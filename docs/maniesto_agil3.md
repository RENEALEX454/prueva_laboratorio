# Principio 3 del Manifiesto Ágil

## Colaboración con el cliente

El tercer principio del Manifiesto Ágil establece que **la colaboración con el cliente es más importante que la negociación contractual**. Se busca trabajar de manera cercana con el cliente para comprender sus necesidades y adaptar el proyecto cuando sea necesario.

* Mantener una **comunicación constante** con el cliente.
* Escuchar sus **necesidades y sugerencias**.
* Adaptarse a los **cambios durante el proyecto**.
* Entregar un producto que **cumpla con las expectativas del cliente**.
